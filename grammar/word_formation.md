# Uro Word Formation

Uro grows its vocabulary in two ways:

1. **Adapting international words** with fixed spelling rules (§4). Europeans already know these words, so they cost nothing to learn.
2. **Deriving words** from existing Uro roots with a small set of affixes (§1–§2) and transparent compounds (§3).

All affixes are taken from international vocabulary, so a learner recognizes them from words they already know (*pianist, nation, university, electric, active*).

---

## 1. Suffixes

| Suffix | Meaning | Examples |
|--------|---------|----------|
| `-ist` | person: profession, follower | `piano` → `pianist`; `turist`; `artist` |
| `-or` | person or thing that acts | `autor`, `direktor`, `aktor` |
| `-sion` | action or result (English *-tion*, *-sion*) | `nasion`, `stasion`, `informasion` |
| `-iti` | quality, state (English *-ity*) | `universiti`, `kualiti`, `realiti` |
| `-ism` | doctrine, system | `turism`, `sosialism` |
| `-logi` | field of study | `biologi`, `teknologi` |
| `-al` | adjective: "relating to" | `nasional`, `normal`, `sentral` |
| `-ik` | adjective: "of the kind" | `elektrik`, `publik`, `klasik` |
| `-iv` | adjective: "tending to" | `aktiv`, `positiv` |
| `-li` | adverb (optional variant) | `rapid` → `rapidli`, `feli` → `felili` |
| `-a` | female (optional) | `chiko` → `chika`, `on` → `ona` |
| `-ed` | past tense / participle | `work` → `worked`, `vider` → `videred` |

> **Not `-er` for people.** In Uro `-er` is the verb ending (`speler` = to play), so it is never used for agent nouns (*player*, Dutch *speler*) or comparatives (*bigger*). Use `-ist`/`-or` for people and `mer` for comparison.

## 2. Prefixes

| Prefix | Meaning | Examples |
|--------|---------|----------|
| `non-` | not | `non-normal`, `non-publik` |
| `re-` | again, back | `re-vider` (see again) |
| `eks-` | former | `eks-president` |
| `anti-` | against | `anti-sistem` |
| `pre-` / `post-` | before / after | `pre-historik`, `post-work` |
| `inter-` | between | `internasional` |

`pre-`, `post-`, `inter-` and `eks-` are also prepositions (see [`grammar.md`](grammar.md) §10). A Uro speaker who knows one use knows the other.

## 3. Verb roots, conversion and compounds

- **Verb root as noun**: dropping the verb ending `-er` gives the noun. `frager` (ask) → `frag` (question); `finer` (end) → `fin` (end). A bare-root verb is its own noun: `work`, `help`, `drink`.
- **Compounds** are written as separate words, with the modifier first (as with adjectives): `skola bus` (school bus), `telefon numer` (phone number).
- **Transparent phrases** replace many irregular words of the natural languages. Each copies a pattern that all three families already use:

| Uro | Literally | English | Same pattern in |
|-----|-----------|---------|-----------------|
| `dis den` | this day | today | Russian *se-godnja*, Dutch *van-daag*, English *to-day* |
| `fon novo` | from new | again | Polish *od nowa*, Czech *z-novu*, Portuguese *de novo*, German *von neuem* |
| `pro ke` | for what | why / because | Italian *perché*, Spanish *por qué*, Czech *pro-č* |
| `pro dis` | for this | therefore | Spanish *por eso*, Polish *dlatego* |
| `kan ar` | can be | maybe | Polish *może*, Romanian *poate*, English *may be* |
| `som temps` | some times | sometimes | English *sometimes*, Dutch *soms* |
| `alting` / `somting` / `nulting` | all/some/no thing | everything / something / nothing | Swedish *allting*, English *everything* |
| `somun` / `nulun` | some/no one | someone / nobody | English *someone*, *no one* |
| `in plas fon` | in place of | instead of | Dutch *in plaats van*, Danish *i stedet for*, Romanian *în loc de*, Russian *vmesto*, Croatian *umjesto* |
| `mem if` | even if | although | Danish *selv om*, French *même si*, Czech *i když*, Croatian *iako* |
| `durant ke` | during that | while | French *pendant que*, Spanish *mientras que* |
| `fon kando` | from when | since | Italian *da quando*, Polish *od kiedy*, Croatian *otkad* |
| `un temp` | one time | once | Spanish *una vez*, French *une fois*, German *einmal*, Swedish *en gång* |
| `un alter` | an other | another | French *un autre*, Italian *un altro*, German *ein anderer* |
| `al ke` | all that | whatever | French *tout ce que*, German *alles, was*, Polish *wszystko, co* |
| `pre` + time | before … | … ago | German *vor drei Jahren*, Czech *před třemi lety*, Serbian *pre tri godine* |
| `unka` / `nunka` | ever / not-ever | ever / never | Latin *umquam* / *numquam*, Croatian *ikad* / *nikad*, Dutch *ooit* / *nooit* |

## 4. Adapting international words

International words are taken from the shared European form and adapted with the spelling rules from [`pronunciation.md`](pronunciation.md):

| Source ending / letters | Uro | Examples |
|-------------------------|-----|----------|
| *-tion*, *-sion* | `-sion` | nation → `nasion`, information → `informasion`, station → `stasion`, television → `television` |
| *-ity*, *-ität*, *-ité*, *-idad* | `-iti` | university → `universiti`, quality → `kualiti`, city → `siti` |
| *-ic*, *-ique*, *-isch* | `-ik` | electric → `elektrik`, music → `muzik`, public → `publik` |
| *-ive*, *-iv*, *-ivo* | `-iv` | active → `aktiv`, positive → `positiv` |
| *-ism*, *-isme*, *-ismo* | `-ism` | tourism → `turism` |
| *-ology*, *-ologie*, *-ologia* | `-logi` | biology → `biologi` |
| *-y* (vowel) | `-i` | family → `famili`, taxi → `taksi` |
| *-le* | `-el` | example → `eksampel` |
| *c* /k/, *ch* /k/, *ck*, *q* | `k`, `ku` | club → `klub`, technology → `teknologi`, quality → `kualiti` |
| *c* /s/ | `s` | centre → `sentrum`, social → `sosial` |
| *x* | `ks` | taxi → `taksi`, example → `eksampel` |
| *ph* | `f` | telephone → `telefon`, photo → `foto` |
| *th* | `t` | technology → `teknologi`, theme → `tema` |
| *z* pronounced /z/ in the source | `z` | music → `muzik` |

Rules for choosing the form:
1. Prefer the form that is **shared by most of the Germanic, Romance and Slavic languages** (e.g. `bilet`: Polish *bilet*, Russian *bilet*, Romanian *bilet*, French *billet*, Danish *billet*, Swedish *biljett*).
2. If the forms differ, prefer the **shortest recognizable** one (`bus` rather than `autobus`).
3. Remove grammatical endings of individual languages (*-o*, *-a*, *-e*, *-um*, *-us*) unless they are needed for pronunciation (`auto`, `piano`, `radio` keep their vowel).
